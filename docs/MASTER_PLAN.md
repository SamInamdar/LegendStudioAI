# Legend Studio AI

## Vision

Legend Studio AI is a production-grade AI platform that converts plain text stories into cinematic videos for YouTube Shorts, Instagram Reels, TikTok and other platforms.

The project focuses on:

- High quality
- Low generation cost
- Maximum automation
- Asset reuse
- Modular architecture
- Provider independence

---

# Development Principles

1. Cache before generating
2. Never duplicate assets
3. Modular design
4. Production-ready code only
5. Configuration driven
6. Every sprint must be runnable
